# **3\. Guía visual**

El juego usa pixel art propio: un hábitat cálido rodeado del frío de Marte, una noche azul oscura y, en las crisis, luces rojas de emergencia. Estas reglas hacen que el arte de varias personas parezca de un solo juego.

## **Dirección de arte**

Tomamos ideas de estructura, no de apariencia. Todo lo que se ve y se oye es nuestro.

* **Copiamos el ritmo:** pantallas fijas con texto, un mapa con lugares para visitar y un reloj que avanza hasta las 6:00 AM.  
* **No copiamos:** personajes, música, fuentes, sprites, colores característicos ni la distribución de mapas de otros juegos.  
* **Dentro del hábitat:** zonas cálidas y acogedoras, con luz de las cápsulas y pantallas.  
* **Afuera:** frío, azul muy oscuro y poca luz.  
* **Crisis:** luces rojas de emergencia (sobre todo en la Noche 7\) y retratos de la tripulación que miran fijo a la cámara.  
* **Tarjetas de dato real:** aparecen al salir de cada estación y se separan visualmente de la ficción.  
* **Bocetos:** el arte actual del proyecto es provisional y original, con la medida y el nombre finales.

## **Medidas y formato**

Todo el arte se dibuja a la resolución base para que los píxeles tengan el mismo tamaño en todo el juego.

| Elemento | Medida o ajuste (PPU \= 32\) | Imagen | Notas técnicas |
| :---- | :---- | :---- | :---- |
| Resolución base | 640 × 360 px, ampliada 3× a 1920 × 1080 |  | Escalado entero sin distorsión de píxeles |
| Bloques del mapa | 32 × 32 px |  | 1 × 1 unidad de Unity |
| Personaje | 32 × 48 px |  | 1 × 1.5 unidades |
| Hoja del personaje | 128 × 192 px |  | 4 columnas por 4 filas de celdas de 32 × 48 |
| Estación en el mapa | 64 × 64 px |  | Ocupa 2 × 2 bloques |
| Retrato de tripulante | 96 × 96 px |  | Cada uno tiene además su versión \_mirada (en crisis, mirando fijo a la cámara) |
| Fondo de estación | 640 × 360 px |  | Pantalla completa |
| Planta | 48 × 48 px |  | Una imagen por planta y estado |
| Cápsula de cultivo | 80 × 100 px |  | Hidropónica y regolito |
| Página del manual de plantas | 300 × 304 px |  | Solo el papel: el texto lo escribe el juego |

## **Hoja de sprites del personaje**

El personaje usa una sola hoja que Unity corta en celdas. Para cambiar el dibujo, se reemplaza el PNG con el mismo nombre y la misma rejilla.

* **Archivo:** Assets/Comun/Art/Personajes/spr\_jugador\_hoja.png, de 128 × 192 px.  
* **Celda:** 32 × 48 px.  
* **Columnas:** el frame 0 es quieto; los frames 1, 2 y 3 forman la caminata.  
* **Filas, de arriba hacia abajo:** abajo, izquierda, derecha, arriba.  
* **Apoyo:** los pies tocan el borde inferior de la celda.  
* **Velocidad:** 8 frames por segundo.

## **Pantalla de juego**

* **Mapa:** arriba van la hora, la batería, el oxígeno, el agua, la comida, el rescate, el domo y el pulso de cada tripulante en verde, amarillo o rojo.  
* **Pantallas de las 18:30 y de las 6:00 AM:** panel oscuro casi opaco con el título arriba y el texto en el centro.  
* **Estaciones:** cada una tiene su fondo y su propia barra de hora y batería.  
* **Tutorial:** ventana azul oscura con borde amarillo y el botón "Entendido".

### **Viñetas de la intro**

La narrativa conserva ocho pantallas de texto. Las ilustraciones finales disponibles son cinco, por lo que la secuencia visual configurada es **1, 2, 3, 4, 5, 1, 2, 3**. Los textos de las pantallas 6 a 8 no se repiten: solo se reutilizan las imágenes 1 a 3.

## **Cómo reemplazar un boceto**

1. Dibujar con la misma medida del boceto.  
2. Guardar como PNG con el mismo nombre, encima del archivo viejo.  
3. Subirlo a GitHub junto con su archivo .meta.

Unity configura cada PNG automáticamente: Sprite, 32 píxeles por unidad, Point y sin compresión. Los bloques del mapa se pueden repintar con la Tile Palette de Unity; están en Assets/Comun/Art/Bloques/Tiles.
